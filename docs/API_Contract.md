# Prototype API contract

The same API serves local and Netlify hosted review. Hosted mutations require a trusted HTTPS Origin as well as `X-Prototype: local` (the simulation marker is not authentication). GET `/api/runtime` returns `{hosted,simulation:true}`. Hosted admin credentials use a private function-only review password, not the local demo password below. Hosted sessions, ledger and retry records persist transactionally in Postgres; login cookies are Secure/HttpOnly/SameSite=Strict. No live payment or email adapters exist.

All money values returned by API are cents; UI displays dollars. Amount/fee input accepts dollars as numbers or strings. All mutations require header `X-Prototype: local`. Admin session cookie set on login, credentials same-origin. JSON errors `{error}` with 4xx. Tokens in URL paths only for private athlete onboarding and opt-out/donor-choice capabilities; never log them. Initial sample campaigns draft. Every admin response scoped to authenticated org. Clock is per campaign with `now` ISO timestamp, used for prototype scheduler only.

## Login
POST /api/login `{email,password}` -> `{organization}`. Demo credentials `coach@tvvc.example` or `coach@century.example`, password `prototype-only` (deliberately generated local demo credentials, no real credentials). POST /api/logout. GET /api/session -> `{organization}` or 401. GET /api/examples (public) -> `{campaigns:[{name,slug,organizationName}]}`.

## Admin
GET /api/admin -> `{organization,campaigns:[...]}` (campaigns include full detail below).
POST /api/admin/campaigns `{name,purpose,goal,startDate,endDate,timezone}` -> campaign detail. POST /api/admin/campaigns/:id/duplicate `{name}` -> new draft with settings only (no contacts, athletes, money, jobs).
PATCH /api/admin/campaigns/:id `{name,purpose,goal,startDate,endDate,timezone,color,logo,organizationName,paymentSettings,schedule}` -> detail. Logo is optional PNG/JPEG/WebP data URL under 2MB. Payment settings `{stripe:{enabled},venmo:{enabled,profile,instructions},school:{enabled,url,instructions},check:{enabled,payee,address,instructions}}`; blank placeholders. schedule array `[{id,day,enabled,subject,body}]`; tokens `{{organization}}`, `{{campaign}}`, `{{athlete}}`, `{{message}}`, `{{link}}`. Day1 required invitation. Dates/timezone lock after launch; schedules/templates remain editable with future-window rescheduling and no repeat delivered steps.
POST /api/admin/campaigns/:id/action `{action:'launch'|'pause'|'resume'|'close'|'run'|'advance',days?}` -> detail. Run simulates jobs, advance moves campaign clock then runs (paused campaigns don't send). Resume skips overdue jobs. Closing permanent. Server also stops at deadline.
POST /api/admin/campaigns/:id/athletes `{name,displayName,team}` -> `{athlete,privatePath}`.
POST /api/admin/campaigns/:id/import `{csv}` -> `{imported:[{athlete,privatePath}],errors:[{row,error}]}` (validates whole CSV before mutation; headers name,displayName,team).
POST /api/admin/campaigns/:id/athletes/:athleteId/invite `{}` -> `{privatePath}` rotates/revokes previous link.
POST /api/admin/campaigns/:id/athletes/:athleteId/approve `{approved:true,authorizationNote}` -> detail; authorization note required, approved profile snapshot reused until new profile approved. Can revoke with `{approved:false}`.
POST /api/admin/campaigns/:id/ledger/:donationId `{action:'confirm'|'reject'|'refund'|'correct'|'attribute',amount?,fee?,method?,receivedDate?,transaction?,athleteId?,note,requestId}` -> detail. confirm/correct require amount, method, date; blank fee unknown; transaction when available. note required for audit. Duplicate transaction per org+method blocked.
POST /api/admin/campaigns/:id/suppress `{email,reason:'unsubscribe'|'complaint'|'hard_bounce'}` -> detail. POST /api/admin/campaigns/:id/jobs/:jobId/retry `{}` -> detail (simulated failure retry only; idempotent). POST /api/admin/campaigns/:id/jobs/:jobId/fail `{}` -> detail (mark queued simulated failure). GET /api/admin/campaigns/:id/export -> CSV.

Campaign detail: `{id,orgId,name,slug,purpose,goalCents,startDate,endDate,timezone,color,organizationName,status,now,paymentSettings,schedule,athletes:[{id,name,displayName,team,completed,approved,photo,message,authorization,invitationStatus,privatePath?,totalCents}],contacts:[{id,email,athleteIds,state}],ledger:[{id,reference,donorName,email,amountCents,feeCents:null|number,method,status,athleteId,receivedDate,transaction}],jobs:[{id,type:'solicitation'|'thank-you',day,dueDate,status,recipient (masked),subject,body,reason?}],activity:[{id,at,type,detail}],audit:[{at,actor,action,donationId,before,after,note}],totals:{grossCents,knownFeeCents,knownNetCents,unknownFeeCount,donationCount},teamTotals:[{team,totalCents}]}`. Job body previews include public paths and opt-out path but no recipient/private invitation tokens in activity log. PrivatePath demo issued links available to authenticated org; stored locally in separate ignored capability file.

## Athlete
GET /api/athlete/:token -> `{athlete:{id,name,displayName,team,photo,message,completed,approved,authorization},campaign:{name,status,slug,organizationName},contacts:[email],publicPath}`. Token hashed server-side, revocable. PATCH /api/athlete/:token `{emails?:string,displayName?,message?,photo?:dataURL,authorization?:boolean,done?:boolean}` -> previous shape + `{contactResult:{added,duplicates,invalid}}`. Contacts split whitespace/comma/semicolon, case-insensitive, athlete private contacts only. Valid entries added even with invalid entries; done requires no invalid input. Profile save invalidates approval if public fields changed. Photo PNG/JPEG/WebP data URL max 2MB. Done can use <20 or zero contacts; acknowledgement required for photo/message publication approval. Server queues only approved completed athletes after launch.

## Public / donor
GET /api/public/:slug?athlete=:id&contact=:token -> `{campaign:{id,name,slug,purpose,goalCents,startDate,endDate,timezone,color,organizationName,status,paymentSettings,receiptWording},athletes:[{id,displayName,team,photo,message,totalCents}],athlete:null|{...},totals,associations:[athleteId],publicPath}`. No contacts, private links, donor email or audit. Unapproved personal message/photo hidden; generic athlete entry still usable.
POST /api/public/:slug/donations `{requestId,amount,email,donorName,method,athleteId?,transaction?,intent?}` -> `{donation:{id,reference,status,amountCents,method,reported},receiptToken,paymentSettings}`. Starts pending. For external payment, `intent:true` reserves a reference before payment and does not pause reminders (`reported:false`). Omitting intent submits a donor report for backward-compatible tests. Stripe pending is simulator checkout. Method must enabled; disallow new donation when draft/closed/after deadline (preview pages still viewable). Request idempotent scoped to payload.
POST /api/receipt/:token/report `{requestId,amount,transaction?}` -> `{donation,receiptWording}`. Reports a reserved external payment; sets reported true and pauses reminders indefinitely pending resolution. Allowed after campaign close for references already reserved. Repeated same request safe; changed payload conflicts.
POST /api/simulator/payments `{receiptToken,eventId}` -> `{donation}`. A receipt token only authorizes the pending demo Stripe payment; server event verifies mock signature/receipt, records event once, confirms ledger. Never trusts browser success state. No Stripe network calls or live webhook exists. Repeated event id/idempotency safe. Other method cannot confirm here.
GET /api/receipt/:token -> `{donation,receiptWording}`. No personal donor/contact data.
POST /api/unsubscribe/:token `{}` -> `{success:true}`. Token from preview email `body` opt-out path (same campaign donor-choice token). Org-wide suppression across campaigns, queued fundraising jobs blocked. Non-soliciting thank-you acknowledgements remain transactional; complaints/hard bounces block them too.

CSV outputs neutralize spreadsheet formulas. Dates YYYY-MM-DD; timezone Intl-valid IANA identifier. Campaign now can advance only forward. Seed includes completed approved sample Maya/Alex sharing supporter@example.test and incomplete Jordan, plus Century sample Casey. No public real school/club logo/credentials/configuration. Unknown fees null. Thank-you acknowledgements contain no solicitation link: unsubscribe stops fundraising only, while complaints/hard bounces stop all delivery.
